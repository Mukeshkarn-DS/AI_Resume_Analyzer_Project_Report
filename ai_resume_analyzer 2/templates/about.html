About This Project

The AI Resume Analyzer and Career Guidance Portal is a Data Science project that uses Natural Language Processing and Machine Learning to analyze resumes and provide personalized career guidance.

Technology Stack

  • Backend: Python, Flask
  • NLP: Regex-based extraction
  • ML: scikit-learn (TF-IDF, Cosine Similarity)
  • Data: pandas, NumPy
  • Frontend: HTML, CSS, JavaScript

Features

  • PDF and DOCX resume parsing
  • Skill extraction from resume text
  • 100-point resume scoring
  • ML-based job recommendations
  • Skill gap analysis and course suggestions
